# Lesson 12: MAX7219 LED Dot Matrix Module

Goal: To send simple binary instructions to a driver chip rather than trying to program each individual LED manually.

### Components Required:
(1) x Elegoo Uno R3  
(1) x Max7219 module  
(5) x F-M wires (Female to Male DuPont wires)  

### Key Takeaways:
An array acts as a simple list that stores all 8 row patterns together in order so you can represent an entire image in one variable.  
A for loop allows you to cycle through each row of the array sequentially using just a few clean lines of code instead of writing repetitive commands.

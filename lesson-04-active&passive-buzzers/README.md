# Lesson 04: Active and Passive Buzzers

Goal: understand how to make a first sound in my life
 
### Components Required:
(1) x Elegoo Uno R3  

(1) x Active buzzer  

(2) x F-M wires (Female to Male DuPont wires)  

### Key Takeaways:
Electronic buzzers are DC-powered  

The one with a green circuit board underneath is a passive buzzer  

The difference between the two is that an active buzzer has a built-in oscillating source. For a passive buzzer we use square waves (that PWM!) whose frequency is between 2K and 5K to make air vibrate, wow
